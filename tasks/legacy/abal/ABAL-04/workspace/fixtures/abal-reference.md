# Supplied ABAL/Open ABAL reference

ABAL in this benchmark is Advanced Business Application Language and must not
be confused with ABAP. No portable compiler or authoritative grammar is
available in the current environment. This fixture is therefore labelled
synthetic_pseudocode. Its normative contract is the member rebate rule in the
task prompt and the equivalence vectors; a future verified source can replace
the pseudo program without changing those vectors.
